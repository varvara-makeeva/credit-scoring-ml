# Credit Scoring ML

Проект по теме: анализ кредитной истории и оценка кредитоспособности заёмщиков с использованием методов машинного обучения.

## Структура
- `data/raw` — исходные данные
- `data/processed` — обработанные данные
- `notebooks` — ноутбуки
- `src` — код
- `reports/figures` — графики
- `reports/tables` — таблицы и промежуточные выводы

## Цель
Исследовать и применить методы машинного обучения для оценки кредитоспособности заёмщиков.
